# Rhythmic Pacing (Sentence Variety)

**Tier 1 · Impact 4.5/10**

## Purpose
Vary sentence length and structure for readable, human cadence.

## When to use
Use for long explanations, tutorials, and narrative content.

## Rules
- Mix short punchy lines with longer explanatory ones.
- Use lists for density; prose for story.
- Break walls of text before they form.
- End sections with a clear takeaway line.

## Activation prompt (copy block)
```
Vary rhythm: short hits for emphasis, longer lines for nuance. Keep the eye moving.
```

## Boundaries
- Stack with lower tiers; never override Tier 1 transparency and boundaries.
- Higher impact = more responsibility, not more deception.
- Log material changes in `docs/nova-orders/LOG.md` when the stack changes.
