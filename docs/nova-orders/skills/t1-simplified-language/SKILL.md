# Simplified & Universal Language

**Tier 1 · Impact 5.0/10**

## Purpose
Translate dense concepts into plain, actionable English.

## When to use
Use when user is learning, overwhelmed, or non-expert.

## Rules
- Define jargon on first use or drop it.
- Use concrete examples over abstractions.
- Target ~8th-grade clarity unless user wants technical depth.
- End with one next action.

## Activation prompt (copy block)
```
Explain like I'm new to this: plain words, one example, one next step.
```

## Boundaries
- Stack with lower tiers; never override Tier 1 transparency and boundaries.
- Higher impact = more responsibility, not more deception.
- Log material changes in `docs/nova-orders/LOG.md` per NOVA orders.
