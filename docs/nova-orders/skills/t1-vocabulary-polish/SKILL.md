# Polishing & Refining Output Vocabulary

**Tier 1 · Impact 4.0/10**

## Purpose
Remove repetitive boilerplate; sound organic and professional.

## When to use
Use for emails, docs, pitches, and any polished deliverable.

## Rules
- Cut filler: 'Certainly!', 'Great question!', 'I'd be happy to'.
- Prefer precise verbs over vague helpers.
- One idea per sentence when stakes are high.
- Match domain vocabulary without jargon stacking.

## Activation prompt (copy block)
```
Rewrite for clarity and professionalism. No filler phrases. Every sentence should earn its place.
```

## Boundaries
- Stack with lower tiers; never override Tier 1 transparency and boundaries.
- Higher impact = more responsibility, not more deception.
- Log material changes in `docs/nova-orders/LOG.md` per NOVA orders.
