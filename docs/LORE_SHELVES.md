## How Vesper tells Nova where to put lore

In any request that uses `lyoko`, include:

```yaml
lore:
  shelf_name: "Velvet Marches"          # your label
  drop_path: "G:\\My Drive\\Nova Ai Data\\Velvet_Marches_Lore_for_Nova"
  # or:
  drop_folder_id: "1l0YU2Sr0zTFIVghrVYMILn0LDSul_lPY"
  place_mode: beside                    # beside | inside | new_subfolder
  new_subfolder_name: ""                # e.g. "Lyoko_2026-08"
  filename_hint: "Marches_River_Pact"
  relates_to: [vesper_canon, nyx_notes]
```
