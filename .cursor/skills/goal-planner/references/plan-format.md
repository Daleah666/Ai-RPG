# Campaign Codex format

Write in the user's language. Keep the headings. Fill every section; do not leave placeholders.

```markdown
# Campaign Codex

<one short narrative: main quest, what was cut, the live tension, hours/energy>

---

# <Quest name>

**<plain title>** · <domain> · <horizon>

This is a **main|side|later** quest. <one sentence on how hours are claimed>

## Why this, now

<quote them, then interpret>

## Done when

<observable outcome for this horizon>

## Constraints I will honor

- Honor: “…”

## What you already told me

- (goal|constraint|…) …

## Campaign map

### Phase 1 — <name>
<intent>

- moves

### Phase 2 — <name>
…

## This week's moves

1. …
2. …
3. …

## If this goes sideways

- **<risk>**
  If-then: …

## Review

- When, questions, what happens if a sitting slips twice

## How to work the hours

<one sitting recipe>
```

Main quests first, then side, then later. Later quests can be shorter but still get a done-when and a "do not start unless" line.
