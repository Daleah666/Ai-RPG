Studio

Audio layers + visual flash + API — one system.

Stack 3 frequency layers into one MP3, flash multiple images from any drive, or generate via HTTP API from Cursor or any script.

Quick start

pip install -r requirements.txt
python3 serve.py
3-layer audio mixer Visual flash API schema

How the 3 layers stack

  1. Layer 1 — normal speech band (300–3400 Hz)
  2. Layer 2 — mid shift (~1.6× pitch, 2–8 kHz)
  3. Layer 3 — upper band (12–17 kHz emphasis)

Each layer has its own affirmations, volume, and frequency profile. FFmpeg mixes all layers on top of your music (or silent base).

Cursor / agent API

curl -X POST http://localhost:8080/api/v1/generate \
  -H "Content-Type: application/json" \
  -d @subliminal/examples/3-layer-job.json \
  -o output.mp3
