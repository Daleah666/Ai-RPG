# Ai-RPG

Project files and on-demand tools, owned by Del.

- `docs/AI_HANDOFF_BRIDGE.md` — share a specific task between tools.
- `skills/subliminal-maker-bot.md` — text-writing reference used on request.
- `subliminals/` — existing content and logs.
- `character-card/` — Redz character card (alpha). From that folder, run `python3 -m http.server` and open `index.html`. `?library` opens her picture library. Dropped files and Accept stay in this browser.

No resident persona or automatic planner is assigned by this repository. Opening the repo does not authorize agent launches, schedules, or playback.
