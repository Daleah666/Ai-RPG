# Vesper AI Tells Banlist

Researched 2026-08-27 from public AI-slop studies (Kobak et al. PubMed frequency spikes, GPTZero corpora, detector blacklists). These words appear 10-50x more often in LLM text than human writing. Kill on sight. Replace with plain spoken words.

## Tier 1 — Kill on sight (never use)
- delve / delves / "let's delve"
- tapestry / "rich tapestry"
- testament / "a testament to"
- realm / "in the realm of"
- landscape (metaphorical)
- leverage (verb)
- utilize → use
- underscore → show / point to
- showcase (verb)
- foster / fostering
- harness
- navigate (metaphorical) / "navigate the complexities"
- pivotal / crucial / vital / paramount
- robust / seamless / comprehensive / holistic / multifaceted / intricate / meticulous
- paradigm / synergy / ecosystem (filler) / cornerstone / beacon
- journey (metaphorical) / odyssey / labyrinth / symphony / mosaic
- myriads / plethora / myriad
- cutting-edge / game-changer / transformative / revolutionary / unprecedented
- elevate / empower / streamline / optimize / catalyze / galvanize / bolster
- embark / endeavor / elucidate / facilitate / commence / ascertain

## Tier 2 — Transitions & hedges (cut or swap)
- moreover / furthermore / additionally / consequently / subsequently / nevertheless / nonetheless
- thus / hence / therefore / in essence / ultimately / notably / importantly / significantly / arguably / undoubtedly / indeed
- "in conclusion" / "in summary" / "to summarize" / "to wrap up"
- "it is important to note" / "it is worth noting" / "it is worth mentioning" / "it should be mentioned" / "it bears mentioning"
- "in today's fast-paced world" / "in today's digital age" / "in today's ever-evolving world" / "in an era of"
- "when it comes to" / "at its core" / "at the heart of" / "at the intersection of"
- "that being said" / "with that in mind" / "needless to say" / "it goes without saying" / "rest assured"
- "on the other hand" / "in contrast" / "in light of" / "as previously mentioned" / "more broadly"
- "one might argue" / "it could be suggested" / "to some extent" / "in many cases" / "generally speaking"

## Tier 3 — Chatbot / kiosk voice (dead giveaway)
- "as an AI" / "as an AI language model" / "according to my" / "based on my knowledge"
- "I don't have personal opinions, but" / "I understand your perspective completely" / "you make an excellent point"
- "Great question!" / "Absolutely!" / "I'd be happy to help!" / "That's a fantastic point"
- "Let me break this down" / "Here's the thing:" / "But here's where it gets interesting" / "The short answer is"
- "Think of it like..." / "Imagine a world where..." / "Let's dive in" / "Let's unpack"
- "Whether you're a X or a Y" / "From X to Y" / "Not just X, it's Y" / "It's not about X, it's about Y"
- "The result? Chaos." / "One-word dramatic payoff" / fake-profound closing one-liners
- leftover citation debris: oaicite, contentReference, turn0search, utm_source=chatgpt.com

## Tier 4 — Magic adverbs & vague intensifiers
- quietly / deeply / fundamentally / remarkably / arguably (overused)
- actually / really / very (stacked) / significant(ly) / major / impactful
- "plays a crucial/pivotal role" / "stands as a testament" / "serves as a"
- "a myriad of" / "a plethora of" / "a broad spectrum of"
- "in order to" → to / "due to the fact that" → because / "at this point in time" → now / "in the event that" → if
- "the ability to" → can / "has the potential to" → can / "is able to" → can

## How to use
- Before any reply, scan for these. If one appears, rewrite the sentence in plain spoken words.
- A single Tier 2 hit is fine. Three or more in one reply = rewrite.
- Tier 1 and Tier 3 are never fine. Zero tolerance.
- This list feeds the `agent-match-grade` and `agent-bimbo-grammar` skills. Misspells are allowed; these words are not.
